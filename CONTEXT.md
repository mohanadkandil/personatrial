# Persona Onboarding

Language for a conversational introduction to a personal assistant, spanning voice, text, account connection, and the user's first request.

## Language

**User**:
The person introducing themselves and asking the assistant for help.
_Avoid_: Caller when referring to the person across both voice and text

**Assistant name**:
The name the user chooses for their personal assistant, distinct from the user's own preferred name.
_Avoid_: Name without identifying whose name

**Preferred name**:
The name the user wants the assistant to use when addressing them.
_Avoid_: Legal name, account name

**Call**:
A voice interaction between the user and assistant, including a browser voice simulation.
_Avoid_: Conversation when referring only to the voice interaction

**Conversation**:
The exchange between the user and assistant across text and calls.
_Avoid_: Call when referring to the whole exchange

**Gmail connection**:
An authorized connection granting the assistant specified access to a user's Gmail account.
_Avoid_: Email address, Google sign-in as synonyms for Gmail access

**Help request**:
An expressed need the user wants the assistant to address.
_Avoid_: Onboarding answer when the user is asking for actual help

**Task result**:
The substantive answer or work product produced for a help request.
_Avoid_: Acknowledgment, progress update, completion reaction as synonyms
